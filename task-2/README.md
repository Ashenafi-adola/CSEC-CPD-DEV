# Todo Project

A small TypeScript/JavaScript example that demonstrates a simple todo implementation.

Files included:
- `todo.ts` — TypeScript source
- `todo.js` — Compiled JavaScript (if present)
- `package.json`, `tsconfig.json` — project config

Prerequisites
- Node.js
- TypeScript (optional, used for compilation)

Build & Run
- Install dependencies (if any):

```
npm install
```

- Compile TypeScript (if you modify `todo.ts`):

```
npx tsc
```

- Run the JavaScript file:

```
node todo.js
```

Notes
- If `todo.js` is already present you can run it directly with `node todo.js`. Re-run `npx tsc` after editing `todo.ts` to regenerate the JavaScript output.
